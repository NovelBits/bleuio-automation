# Novel Bits blog code

Runnable code that accompanies the [Novel Bits](https://novelbits.io/) blog. Each folder
supports a series of posts; clone what you need, run it against your own hardware.

## Contents

| Folder | Posts | What it is |
|--------|-------|------------|
| [`bleuio/`](bleuio/) | The "Automate your Bluetooth LE testing" series | Drive a BleuIO Bluetooth LE USB dongle from the command line: a serial helper, a scripted-session test runner, and example scripts. |
